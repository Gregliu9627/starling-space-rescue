# STARLING · 星际小队

一个适合 iPad 横屏游玩的太空飞船英语游戏。使用 HTML、CSS、JavaScript 和 Canvas 编写，无需构建、账号或游戏服务器。

## 操作与任务

- 首页「开始射击 · 选关」进入 37 个可自由选择的词汇射击关卡；「随机混合关」每次抽取一组新词。
- 用手指按住空白区域拖动飞船，激光自动发射。
- 点击右下角开启护盾；右上角可以暂停或关闭声音。
- 通过「再听一次」重播英文任务指令。
- 完成收集星星、颜色瞄准、方位救援与守卫挑战。
- 电脑也支持方向键 / WASD 移动、空格键开启护盾。

全部 186 个词都可作为射击目标。原来的 `three stars`、`red`、`blue`、`green`、`behind` 和 `in front of` 救援流程保留在选关页的「经典救援练习」。
答错后会解释词义并允许重试；护甲耗尽后可修复飞船，继续当前任务。

## 自由选关与随机组合

- 12 个新主题各分成 3 关、每关 5 词，加上 1 关 6 词的太空入门，共 37 关。词组之间不重复，覆盖全部 186 词。
- 所有关卡直接开放，按主题筛选或翻页即可选择；出发前能看到本关词组，也可点词卡预习、调整难度。
- 每次进入关卡，目标词的出场顺序随机排列。每次正确命中后，正确目标换位置，并更换至少一个干扰词；主题关的所有目标均来自本关词组。
- 通关后可以直接进入「下一关」、重玩或自选其他关。下一关使用不同的词组；暂停时也能换关。
- 「随机混合关」从全部词库抽取 6 个不同词，可以在准备页重抽。重抽和下一组会避开上一组的词。
- 关卡完成次数单独保存在当前浏览器，原有救援、认词、巡航和难度数据保留；复习结果页不会重复增加通关次数。

## 看词、听词、认词

- 每轮第一次遇到新词，会先暂停战斗，展示图示、大字号英文、中文意思、字母和例子。可以听单词、短语和字母，点「出发」再继续。
- 战斗指令中的重点词会高亮；无人机、星星、机器人和能量球旁显示对应的英文。任务下方的单词按钮可随时打开卡片，阅读期间不会受到伤害。
- 首页「单词舱」可以按主题、起步 / 拓展难度浏览全部 186 个词，支持中英搜索和翻页；星星卡片同时介绍复数 `stars`。
- 单词舱和通关页提供「认词小挑战」：看图和中文，从三个英文选项中配对。抽象词用释义和留空的例句出题。不计时，选错会解释并允许重试，选择后朗读该词。
- 认词记录独立统计首次选对和重试情况，方便家长观察孩子是否能把图片含义与英文拼写对应起来。复习卡片不会重复增加救援次数或认词轮数。

## 香港小学主题词库与词汇巡航

保留原来的 6 个太空任务词，另加 12 个主题、每主题 15 词，共 **186 词**。主题为家人朋友、校园生活、动物朋友、食物饮品、身体衣物、我的家、香港出行、自然天气、数字时间、日常动作、感受描述、句子小帮手。

以小一至小三常见生活语境为主，使用繁体中文释义、原创简单例句和英式拼法。包括 `MTR`、`minibus`、`tram`、`rubber`、`lift`、`rubbish bin`、`favourite`、`colour`，以及 `because`、`before`、`after`、`always`、`sometimes` 等不易图示化的词。

新增词中 104 个用设备内置图示，76 个用文字卡；原太空词保留 SVG 图示。图示帮助理解，中文和例句说明本次采用的词义。例如 `sun` / `sunny` 即使图示相似，也有不同释义和例句。英式英文语音优先，可用音色仍取决于设备。

单词舱里的「词汇巡航」仍支持从当前筛选范围选出最多 6 个词进行自定义练习。每词先看卡，再驾驶飞船，从三架带英文的无人机中找出符合释义的词；英文目标不按答案着色。错误命中会解释，正确命中后目标组合和位置都会变化。所有词汇射击关沿用已保存的陨石速度、数量和命中要求，通关后可复习本轮词或进行认词挑战。

练习优先选择未练过的词，再复习最近需要重试的词，避免每次只出现第一页。词汇巡航与认词挑战分别记录；打开卡片不会增加练习次数。升级保留原有救援、认词和难度数据。

选词依据：[香港教育局《英语课程指引（小一至小六）》2025，第 24 页及附录 12](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/eng-edu/Curriculum%20Document/Pri_ELCG_Primary_1-6_2025.pdf)，以及[小学词汇学习资源](https://www.edb.gov.hk/en/curriculum-development/kla/eng-edu/references-resources/resource%20pri_vocab.html)。课程建议结合语境和任务学习词汇。本库是按这些方向编选的练习材料，**不是官方必背词表，也不对应某套学校课本**；「起步 / 拓展」为游戏内难度分组。

## 可调难度

首页「任务难度」、出发前的准备页和暂停菜单都可以调整：

| 选项 | 范围 | 默认探险档 |
| --- | --- | --- |
| 陨石速度 | 0.5–3 倍，每次调整 0.25 倍 | 1.5 倍 |
| 陨石数量 | 每波 1–6 颗 | 每波 3 颗 |
| 每项射击任务命中 | 2–20 次 | 6 次 |

提供「练习」「探险」「王牌」预设，也可分别调整三个选项。速度和数量也用于 Boss 弹幕；目标次数用于颜色任务、词汇巡航和每层 Boss 护盾。收集星星和方位救援的数量保持不变。

每次正确命中后，下一目标会换位置。暂停中保存设置后，速度和数量在继续时生效；目标次数从下一项任务生效，当前任务的目标和已完成进度保留。设置独立保存在当前浏览器中，取消调整不会修改已保存设置或学习记录。

## 发布到 GitHub Pages

1. 将本仓库文件上传到 `main` 分支，确保 `index.html` 位于仓库根目录。
2. 在仓库中打开 **Settings → Pages**。
3. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
4. 选择 **main** 和 **/(root)**，点击 **Save**。
5. 等 GitHub 完成部署，在 Pages 页面点击 **Visit site**，获得实际游戏网址。

免费账号通常需要使用公开仓库。游戏网站公开可访问，访客无需 GitHub 或 ChatGPT 账号。
GitHub Pages 在不同地区、网络下的访问情况需要实际测试。

参考：[GitHub Pages 发布来源配置](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## iPad 使用

使用 Safari 横屏打开。首次开始时先点击「听听英文语音」，确认设备音量和语音播放。
英文由设备内置的 `SpeechSynthesis` 朗读，不需要麦克风。可用音色及播放效果由设备和浏览器决定。
语音不可用时仍保留英文字幕。实际 iPad 的语音和性能仍需要实机确认。

## 学习记录

家长舱显示任务完成次数、无误完成次数、选错次数和主动重听次数。
另有「看图认词」记录，显示每个词首次选对 / 完成配对的次数以及完整练习轮数。
词汇巡航有独立的完成轮数和各词练习记录。单词舱可按主题查看每个词的认词结果。
这些是练习记录，不代表已经掌握单词。

记录仅存于当前浏览器的 `localStorage`，不上传到 GitHub，也不跨设备同步。
浏览器清理数据、换用浏览器或换网址后，原来的记录不会自动迁移。
页面不使用第三方统计或外部图片、字体、脚本资源。

## 本地运行与检查

```sh
npm run dev
npm run check
npm test
```

本地预览端口为 `4173`，需要 Python 3；语法与逻辑检查需要 Node.js。没有需要安装的 npm 依赖。

游戏原型已经过 Chromium 触摸模拟的完整通关测试，覆盖拖动、星星收集、错误反馈、重听、暂停、护盾、方位任务、守卫和本地记录持久化。模拟视口包括 1024×768、1133×744 和 768×1024；这不等同于真实 Safari 测试。

认词版另外验证了六张自动单词卡、读卡时暂停计时与陨石、任务重点词高亮、单词舱、配对重试、首次选对统计、复习不重复计数、刷新后记录保留，以及清除学习记录时保留难度设置。

扩展词库的浏览器检查入口为 `node tests/browser-qa.mjs --expanded`，需要本地预览服务器和端口 9225 的 Chromium 调试实例。覆盖主题 / 难度筛选、分页、搜索、抽象词出题、完整词汇巡航、旧记录迁移和 iPad 布局。

选关版检查入口为 `node tests/browser-qa.mjs --levels`，覆盖首页选关、两关连续通关、每次命中后的目标变化、随机重抽、抽象词关卡、完成记录保存及 iPad 横竖屏布局。逻辑检查还逐一验证全部 186 词可作为正确射击目标、37 关完整覆盖词库、关卡词组互不重复。
